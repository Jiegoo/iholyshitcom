# Contributing

This public repository is maintained independently from any operating website. Propose changes through issues or pull requests here; never submit another site's private configuration or Git history.

Keep changes focused. Include clear reproduction steps, relevant tests and updated documentation. Use synthetic data, keep tests local, and never call paid APIs or publish test articles to a live website.

Before submitting code, run the relevant checks from README. Database changes require migrations; this baseline is for new instances and must not be applied over an existing unrelated database.

Contributions should be compatible with this repository's MIT license, with third-party notices preserved. Do not submit passwords, tokens, account data, private prompts, copied articles or brand assets.

Contact: jiegoo@gmail.com. Report security concerns privately as described in SECURITY.md.
